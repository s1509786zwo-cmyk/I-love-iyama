EXTERNAL ASSET EDITION / GLTF 2.0

耳が飾りになるまで

光の届かない回廊。雨音が消えてゆく。
手記を三つ、鍵を一つ。最後の音が消える前に、入口へ戻ってください。

GLTF / GLB2K PBRBVH COLLISION

01 — 探索する

開始時の1クリックでマウスをロック。以後はボタンを押さずに視点移動できます。Escで解除・一時停止。
読込を開始します…
初期デモ：Sponza（日本家屋ではありません）
自動で歩行可能な連結領域を検出し、到達可能な床へ手記・鍵を配置します。入口が脱出地点です。人形の追跡はこの刷新版には含みません。

02 — あなたの屋敷を読み込む

GLBを画面へドロップ。GLTFは .bin・textures を含むフォルダごと、または全ファイルをまとめてドロップしてください。
ローカルファイルは外部へアップロードしません。URLモデルはCORS対応サーバーが必要。Y-up・内装あり・床と壁の実体がある建築モデルを推奨。最大水平寸法を42mへ自動調整します。

03 — 外部PBRマテリアル

Poly Havenの古木・畳・土壁、各2KのBaseColor / Roughness / OpenGL Normal。モデルの材質名と平面形状に応じて自動割当し、不明な材質は原作者の質感を維持します。
テクスチャ取得中…
畳は実物のPBR素材を使用。和紙専用素材は未使用で、モデル内の和紙は原作マテリアルを維持します。自動判定の誤りは「原作の材質に戻す」で解除できます。

04 — 遊び方と制約

WASD：移動 / Shift：早足
E または左クリック：手記・鍵を拾う
F：懐中電灯 / Q長押し：手がかり方向
Esc：マウス解除 / 設定画面

手記ごとに雨音→低いドローン→高いドローンが消え、足音も弱くなります。GLBは約53MB。初回はダウンロード・床解析に時間がかかります。高負荷モデルの60fpsは保証しません。スマホ操作は対象外です。
アセットの出典・ライセンス / 読込に失敗した場合

初期モデル：Sponza Atrium（欧州建築の回廊。古民家・複数の和室ではありません）。Frank Meinl / Crytek、Marko Dabrovic。PBR textures: Alexandre Pestana。配信元：Breush/lava-assets。元モデルの出典・利用条件を確認してください。公開配信は再配布・商用利用許諾を意味しません。製品化時は利用権を確認済みのアセットに差し替えてください。

テクスチャ：Old Wood Floor / Tatami Mat / Clay Plaster（Poly Haven / CC0）。Three.js MIT / three-mesh-bvh MIT。

インターネット接続が必要です。アプリ内のファイルビューアは外部通信・Pointer Lockが制限されるため、ダウンロードしたHTMLをChrome/Edgeで直接開くか、ライブプレビューを別タブで開いてください。CORSを無効化する必要はありません。GLTFの関連ファイルが不足するとロードできません。外観のみの家、閉じた扉、アニメーション付きの壁は自動で通行可能にはなりません。
